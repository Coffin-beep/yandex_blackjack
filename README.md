# 🂡 Блэкджек для Яндекс Игр

Полноценная веб-игра «Блэкджек» для платформы **Яндекс Игры**.
Vanilla JS (ES6+) + CSS + [Vite](https://vitejs.dev/) — без фреймворков и без графических ассетов
(карты, фишки и сукно нарисованы на чистом CSS), поэтому бандл крошечный и грузится мгновенно.

![stack](https://img.shields.io/badge/stack-Vanilla_JS%20%2B%20Vite-646cff) ![yandex](https://img.shields.io/badge/platform-Yandex_Games-ff0000)

## 🎮 Игровые правила

| Правило | Реализация |
|---|---|
| Колода | Шуз из 6 колод, перетасовка Фишера–Йетса при остатке < 25% |
| Дилер | Добирает до 17 (стоит на всех 17, включая мягкие) |
| Блэкджек | Выплата **3:2** |
| Обычный выигрыш | **1:1**, ничья — возврат ставки |
| Действия | **Hit** (Ещё), **Stand** (Хватит), **Double Down** (Удвоить — на первых двух картах) |
| Ставки | Фишки 10 / 25 / 50 / 100 / 500, повтор прошлой ставки, очистка |
| Баланс | Старт 1000, сохраняется между сессиями; бонус +1000 при банкротстве |

**Горячие клавиши (desktop):** `H` — ещё, `S` — хватит, `D` — удвоить, `Space/Enter` — раздать, `R` — повторить ставку, `Esc` — закрыть окно.

**Меню:** ❓ — правила игры, ⚙️ — настройки звука (музыка вкл/выкл, громкость музыки, звуки вкл/выкл, громкость звуков — всё сохраняется между сессиями).

## 🚀 Запуск и сборка

```bash
# 1. Установить зависимости
npm install

# 2. Разработка (localhost:5173)
npm run dev

# 3. Продакшн-сборка → dist/ (один self-contained index.html)
npm run build

# 4. Локальный предпросмотр сборки
npm run preview

# 5. Тесты игровой логики (node:test)
npm test
```

Итоговая сборка — **один файл `dist/index.html`** (CSS и JS инлайнятся через
`vite-plugin-singlefile`). Именно его нужно **заархивировать в ZIP и загрузить**
в [Консоль разработчика Яндекс Игр](https://games.yandex.ru/console/).
Никаких внешних ассетов — SDK Яндекса подключается платформой отдельно.

> При локальном запуске (`npm run dev`) Yandex SDK недоступен — игра автоматически
> работает в **мок-режиме**: реклама и сохранения эмулируются, данные кладутся в
> `localStorage`. Логика игры при этом полностью идентична продакшну.

## 📦 Структура проекта

```
├── index.html            # точка входа + <script src="https://yandex.ru/games/sdk/v2">
├── vite.config.js        # Vite: base './', single-file сборка, dev-server 0.0.0.0
├── src/
│   ├── main.js           # бутстрап: SDK → профиль → UI → LoadingAPI.ready()
│   ├── styles/main.css   # казино-стиль: сукно, карты, фишки, адаптив
│   └── js/
│       ├── sdk.js        # Yandex SDK v2: init, реклама, Player Data (+ мок-фолбэк)
│       ├── storage.js    # профиль игрока: баланс, статистика, настройки (облако + localStorage)
│       ├── deck.js       # колода/шуз/перемешивание/подсчёт очков (чистая логика, тестируется)
│       ├── game.js       # конечный автомат блэкджека: фазы, hit/stand/double, расчёт выплат
│       ├── ui.js         # DOM, анимации раздачи, фишки, баннеры, реклама между раундами
│       ├── audio.js      # звуковые эффекты без ассетов — синтез через WebAudio
│       └── music.js      # генеративная фоновая музыка (лаунж-луп, WebAudio, 0 КБ)
└── tests/deck.test.js    # unit-тесты логики (node --test)
```

## 🎯 Интеграция Yandex Games SDK

- **Подключение:** `<script src="https://yandex.ru/games/sdk/v2">` в `index.html`.
- **Инициализация:** `YaGames.init()` в `src/js/sdk.js` при старте (`src/main.js`),
  после готовности вызывается `ysdk.features.LoadingAPI.ready()`.
- **Реклама:** `ysdk.adv.showFullscreenAdv()` показывается **между раундами — каждые 3
  сыгранных раздачи**, но не чаще одного раза в 65 секунд. На время рекламы игра
  ставится на паузу, звук выключается (`onOpen`/`onClose`).
- **Сохранения:** баланс, статистика и настройки пишутся через `ysdk.getPlayer()` →
  `player.setData()` (облако) **и** дублируются в `localStorage` — сессия восстанавливается
  мгновенно даже до ответа облака. Вне платформы работает только `localStorage`.
- **Фолбэк:** любой сбой SDK не ломает игру — включается мок.

## 📱 Адаптивность

- Полноценная работа в **Landscape и Portrait** (media-запросы по ориентации,
  размеры карт/фишек через `clamp()` от `vmin`).
- Mobile-first: `touch-action`, запрет зума и контекстного меню, safe-area для «чёлок».
- На desktop — hover-эффекты и горячие клавиши.

## 🔊 Звук и музыка

Звуковые эффекты (карты, фишки, выигрыши) и фоновая музыка **синтезируются через
WebAudio API** — 0 байт ассетов. Музыка — спокойный генеративный лаунж-луп
(92 BPM: контрабас, аккорды, разреженная мелодия по пентатонике), стартует после
первого касания (политика автоплея браузеров) и приостанавливается при скрытии вкладки.
Управление — в меню ⚙️: вкл/выкл и громкость отдельно для музыки и эффектов.

## 📝 Публикация на Яндекс Играх (кратко)

1. `npm install && npm run build`
2. Упакуйте содержимое `dist/` (один `index.html`) в ZIP.
3. Загрузите архив в Консоль разработчика, укажите ориентации (лучше все), иконки.
4. В черновике проверьте показ рекламы и сохранения (статистика → Player Data).
